# 开博说明：为什么我要写这个博客

写博客这件事我拖了很久。真正让我动手的原因很简单：**我发现自己反复在解决同一类问题，却没有把思路沉淀下来。**

## 这个博客写什么

我会围绕三个方向记录：

- **工程实践**：怎么把代码写得更容易维护，测试怎么写才不痛苦。
- **源码分析**：拆开常用的框架和中间件，看看它们到底是怎么工作的。
- **系统设计**：并发、性能、分布式，以及那些没有标准答案的架构权衡。

> 我的目标不是写「教程」，而是把思考过程讲清楚——包括那些走过的弯路。

## 它是怎么搭起来的

整个站点是**纯静态**的，没有后端、没有构建步骤，直接托管在 GitHub Pages 上：

- 文章用 Markdown 编写，放在 `articles/` 目录里。
- 一个 `articles/index.json` 作为文章清单（标题、日期、标签、摘要）。
- 前端用原生 JavaScript 拉取清单并渲染列表，用 `marked` 在浏览器里把 Markdown 转成 HTML。

这样做的好处是：**零依赖、零成本、可长期维护**。

## 如何新增一篇文章

1. 在 `articles/` 下新建 `your-slug.md`。
2. 在 `articles/index.json` 的 `articles` 数组里加一条记录。
3. 提交并推送到 GitHub，Pages 会自动发布。
