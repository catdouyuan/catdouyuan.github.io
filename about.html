关于我

工程实践源码分析系统设计

你好，我是 catdouyuan。我是一名后端 / 全栈工程师，喜欢把复杂的系统拆开来看清楚它的运作方式，也喜欢把踩过的坑记录下来。

这个博客用来分享我的日常思考，主要围绕这几个方向：

  • 工程实践：可维护的代码、测试策略、工程效率工具。
  • 源码分析：拆解常用框架与中间件的实现细节。
  • 系统设计：分布式、并发、性能与架构权衡。

技术栈

Java · TypeScript · Go · Node.js · PostgreSQL · Redis · Kubernetes。工具会变，但把问题想清楚的方法不变。
